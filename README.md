# AeroX Disk Operating System

**AeroX** is a free and open-source operating system designed purely as a learning experience in order to help people better understand **Assembly** and **C**. We do not have a long term goal. We encourage everyone to open pull requests to contribute to our repository.

## Requirements

Basically doesn't need anything to run. **NASM** and **Make** for compiling and **QEMU** for testing. This will be updated as we add C elements such as the kernel.

## Credits

As a learning project, we have used the code of other projects to develop a complete operating system and would like to credit their work.

### From [x16-PRos](https://github.com/PRoX2011/x16-PRos)
- **/boot/boot.asm:** Originally based on the bootloader from x16-PRos, now significantly reworked.
- **/boot/two.asm:** Some 16-bit ASM was taken from the above file which was in turn from x16-PRos.
