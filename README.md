# AeroX Disk Operating System

**AeroX** is a free and open-source operating system designed purely as a learning experience in order to help people better understand **Assembly** and **C**. We do not have a long term goal. We encourage everyone to open pull requests to contribute to our repository.

## Requirements

Basically doesn't need anything to run. **NASM** for compiling and **QEMU** for testing. This will be updated as we add C elements such as the kernel.
